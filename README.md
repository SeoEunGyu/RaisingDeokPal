덕팔이 키우기
---
> 컴퓨터 바탕화면에 다육 식물을 하나 가져다 놓으면 어떨까?
> 

덕팔이 키우기는 바탕 화면에서 다육 식물을 키우는 방치형 육성 게임입니다.
WPF로 개발을 진행하였습니다.
그래픽 리소스는 외주 작업으로 진행하였으며, 그외에 기능적인 부분은 자체 구현하였습니다.

덕팔이 키우기는 분양 받은 다육 식물을 최대한 오래 키우는 것이 목표입니다.

다육 식물은 물, 햇빛, 영양제 등의 요소를 적절히 유지하는 것으로 자라나며, 오랜 시간 동안 적절한 환경을 유지하지 못하였을 경우 죽어버릴 수도 있습니다.
